# AYWO

Across Years, We're One. Family and friends app for web, Android and iOS. Publisher: to be confirmed by the founder before launch (`docs/GO-LIVE-PLACEHOLDERS.md`).

| Read this | For |
|---|---|
| `docs/BUILD-CONTRACT.md` | How the code is organised and the rules it follows |
| `docs/DEPLOY.md` | GitHub, DigitalOcean, web, Android and iOS |
| `docs/PAYMENTS.md` | Dashboard settings for Razorpay, Stripe, RevenueCat and the stores |
| LLD, PRD/HLD and wireframes PDFs | Sent with this zip: the full specification |

## What is here

| Folder | What |
|---|---|
| `apps/app` | Expo app: one codebase for web, Android and iOS, including the admin web app at `/admin` |
| `apps/api` | Node API: Fastify, phone OTP login, WebSocket chat, payments, jobs |
| `db` | Postgres migrations, seeds and pgTAP rule tests |
| `packages` | Relationship engine, tree layout, Lighten and GEDCOM import, shared rules |
| `locales` | English and Tamil; `pnpm locales:translate` generates the other 61 |
| `scripts` | Translation and relationship-word seeding |
| `.do`, `.github` | DigitalOcean App Platform spec and CI |

Android and iOS projects are generated by Expo at build time, so there are no separate native folders to maintain.

## First run

Copy `.env.example` to `.env`, and `apps/app/.env.example` to `apps/app/.env`. Everything starts on dummy keys, and SMS prints to the console in development.

```bash
pnpm install
```

```bash
npx expo install --check
```

```bash
docker compose up -d
```

Starts Postgres and MinIO (the local file store for photos, voice notes and imports; console at http://localhost:9001, minioadmin / minioadmin). The `.env.example` values already point at it.

```bash
pnpm migrate -- --seed
```

```bash
pnpm typecheck
```

```bash
pnpm test
```

```bash
pnpm test:db
```

```bash
pnpm dev:api
```

```bash
pnpm dev
```

The first `pnpm install` creates `pnpm-lock.yaml`: commit it. The Dockerfile and CI need it.

## What has and has not been checked

The founder's laptop has no Node, so this was checked in a browser engine:

| Check | Result |
|---|---|
| All migrations and seeds on real Postgres (PGlite, version 18) | Pass. Production is 17, so re-run on 17 |
| All pgTAP rule tests | Pass |
| Logic tests: relationship engine, layout, import, GEDCOM, payment helpers, privacy filter, with the founder's real file | Pass |
| TypeScript compiler over all code | No syntax errors; no errors inside our own code |

| Every API route (135) and allowed database function (100 in the /rpc list), end to end on real Postgres with real JSON | 585 of 585 checks pass. Fastify's own plugins were stand-ins |
| All 81 screens with real data from that API (157 renders as different people), and 11 click-through journeys | All clean; journeys pass. Two refusals are expected: a relative opening someone else's merge request or help ticket |
| All 65 screens opened with react-native-web, with Expo modules stubbed and the API faked as loading and as failing | No crashes, nothing blank, no missing translation keys. Screens with real data were not covered |

**Never run:** the real Node server with Fastify's plugins, the app on a phone, the app through Metro with real Expo modules, screens with real data, and every outside service. Third-party libraries had no types in that compile, so wrong library calls can still appear: expect some on the first `pnpm typecheck`. Screens have never been seen rendered, so compare them with the wireframes. The riskiest parts for a real device are pinch and drag on the tree, SOS background location on a locked phone, voice notes, and right-to-left layouts.

## Order of work

1. Get all of First run green on a local machine. Fix what it finds.
2. Web first: `pnpm dev`, press `w`. Sign in with the code printed by the API.
3. Android, then iOS: `docs/DEPLOY.md`. Development builds are needed; Expo Go will not run RevenueCat or background location.
4. Connect real keys one at a time: SMS, SendGrid, Spaces, Razorpay, Stripe, RevenueCat.
5. Admin: `apps/api/src/create-admin.ts` makes the first Admin, who sets up the authenticator second step at first sign-in to `/admin`. Staff, team roles and invites are at `/admin/staff`; everything waiting for staff is at `/admin/work`.
6. Push to GitHub and host on DigitalOcean.
7. Run `pnpm locales:translate` and `pnpm kin:seed` with a real `ANTHROPIC_API_KEY`, then `pnpm locales:check`.

## Waiting on the founder

- Prices for the tree poster, family book and premium invite design (`ORDER_PRICES`, placeholders).
- Company details (XXX on the public pages) and legal review of FAQ, Terms, Privacy, Refunds and Contact: `docs/GO-LIVE-PLACEHOLDERS.md`.
- Native-speaker check of all Tamil, including relationship words.
- Stripe account, for overseas web payments and web Apple Pay.
- SOS: a family contact picked from the tree gets the alert but no automatic call, because handing over their number would leak it. A typed number gets the call.
- Whether the outsider link should show photos of living children.
- Whether comments on memories stay an AYWO Plus feature. They are Plus now.
- Account deletion is immediate, with no grace period.

## Not built

- Merging across two separate trees. Merges work within one tree.
- Payment reconciliation if a provider gives up on a webhook.
- Losing tree access does not remove someone from that tree's chats. The person who made a group chat can remove them.
- A wallet (stored money). Deferred to version 2: RBI prepaid rules and Apple and Google billing rules.
- Automatic refunds of AYWO Plus. Plan refunds stay in the App Store, Play Console, Razorpay or Stripe dashboards; order refunds are in the staff panel.

## App icon and loading animations

| What people see | Where it is |
|---|---|
| App icons | `apps/app/assets` (set in `app.json`) |
| Website icons, install manifest, and the loading page shown before any code arrives | `apps/app/public` |
| Phone launch after the native splash | `src/components/Launch.tsx` |
| Screen and request loading | `PageLoader` and `Spinner` in `src/components/Loaders.tsx` |

The animations are drawn in code, so they stay sharp and small, and they respect the phone's reduce-motion setting. The same designs as GIF and WebP files, for use outside the app, are in the brand folder. Check the first launch on a real phone: the hand-over from the native splash must not visibly jump.

Real family files never go in this repo. For T-IO-01, set `AYWO_LIGHTEN_SAMPLE` to a path outside it.
