# AYWO landing page (aywo.in)

A plain HTML page, no build step: `index.html`, `logo.png`, `mark.png`.

- Served at **aywo.in** (DigitalOcean App Platform static site, or any static host).
- Every "Open AYWO" / "Start" button goes to **app.aywo.in** (the web app).
- Play Store and App Store buttons show "Soon" until the apps are live; then change their `href` and remove the `.soon` badge.
- The Tamil relation words in the tree come from `db/seed/kin_terms/ta.sql`.

Preview locally: open `index.html` in a browser.
